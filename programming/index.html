  • 01 Talent Academy October 2026 Solo project

    go-reloaded

    A command-line text editor in Go. It reads a text file, carries out editing instructions written inside the text, such as (up, 2) or (hex), fixes punctuation, quotes and "a" versus "an", and writes the clean text to a new file. Each rule is a small, unit-tested function, and bad input gets a clear error message instead of a crash.

    InSimply add 42 (hex) and 10 (bin) and you will see the result is 68.

    OutSimply add 66 and 2 and you will see the result is 68.
