    go-reloaded

    A command-line text editor written in Go. It reads a text file, follows editing instructions written inside the text, such as (up, 2), (hex) or (cap), fixes punctuation spacing, quotes and "a" versus "an", then writes the clean text to a new file.

    Each rule lives in its own small function, and unit tests cover the official examples, the audit cases and edge cases such as a missing file or a malformed instruction, which get a clear error message instead of a crash.

    InSimply add 42 (hex) and 10 (bin) and you will see the result is 68.

    OutSimply add 66 and 2 and you will see the result is 68.
